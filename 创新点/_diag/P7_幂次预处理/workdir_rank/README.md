# RANK
Code for paper: Reliable Representation Learning for Incomplete Multi-View Missing Multi-Label Classification. [paper](https://arxiv.org/pdf/2303.17117)

You can run 'python main-final.py' for a demo!
The original link to the five datasets is not available now, you can download the datasets and pre-processed incomplete datasets from [here](https://drive.google.com/drive/folders/1ey17GpSJEYpYchY6Du_AOj5Yzi2Ml7JU?usp=drive_link). 


**Correction**: In Eq. (18-19) of the paper, the subscript letter of C' is 'j' instead of 'i', representing the corresponding category.
